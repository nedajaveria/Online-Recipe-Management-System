# Online Recipe Management System

## Overview
This project is a web-based recipe management application developed using PHP and MySQL. Users can add, view, edit, delete and search recipes along with uploading recipe images.

## Features
- Add Recipe
- View Recipe
- Edit Recipe
- Delete Recipe
- Search Recipe
- Image Upload
- User Registration
- User Login

## Technologies Used
- PHP
- MySQL
- HTML
- CSS
- XAMPP

## CRUD Operations
The system supports:
- Create
- Read
- Update
- Delete
