# Online Recipe Management System

A PHP and MySQL based web application for managing recipes.

## Features
- Add Recipe
- View Recipe
- Edit Recipe
- Delete Recipe
- Search Recipe
- Image Upload
- User Login
- User Registration

## Technologies Used
- PHP
- MySQL
- HTML
- CSS
- XAMPP
